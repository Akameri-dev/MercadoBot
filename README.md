🎭 MercadoBot
Python Discord.py License: MIT

Mercadobot es un bot de discord especializado en simular un mercado semanal, haciendo el trabajo de lo que seria un Excel

✨ Características principales
Gestión de recursos: Permite agregar y quitar recursos de los mercados a gusto propio.
Creacion de mercados: Permite la creacion de diferentes mercados de simulacion.
Comando de actualizacion: Comando simple para actualizar la informacion de los mercados.
